Developer Setup Guide

Cleanslate

Chat-driven CSV cleaning — upload a file, tell the agent what to fix in plain English, watch it inspect, decide, and act on your data.

~15 min Node.js 18+ Clerk Supabase Groq
1get

Clone the repo

Pull the project down and move into the app folder.

Shell
$ git clone https://github.com/priymore04-lab/AI_DATA_CLEANSING_TOOL.git
$ cd AI_DATA_CLEANSING_TOOL/cleanslate
2node

Install Node.js

Grab the LTS build from nodejs.org if you don't already have it, then confirm it's on your path.

Shell
$ node -v
$ npm -v
3deps

Install dependencies

Pulls in Next.js, React, Clerk, Supabase, and Papaparse.

Shell
$ npm install
4keys

Create three free accounts

Cleanslate leans on three outside services. Each has a free tier — no card needed.

ClerkAuth

Sign up at dashboard.clerk.com → new application → API Keys → copy the Publishable key and Secret key.

SupabaseDatabase + storage

Sign up at supabase.com/dashboard → new project → run supabase-setup.sql (included in the repo) in the SQL Editor → create a Storage bucket named exactly cleaned-files → copy the Project URL and service_role key from Settings → API.

GroqAI analysis

Sign up at console.groq.com/keys → create a key.

5env

Add your keys

Copy the template and fill in the five values from the step above.

Shell
$ cp .env.local.example .env.local
# then open .env.local and paste in your 5 keys
Don't rename a key to add NEXT_PUBLIC_. In Next.js, only NEXT_PUBLIC_* variables ever reach the browser — that's why Clerk's publishable key and the Supabase URL have it, and why the secret keys don't. If something isn't working, the fix is elsewhere.
6run

Run it

Start the dev server, sign in, and upload a CSV.

Shell
$ npm run dev
  ready - started server on http://localhost:3000
